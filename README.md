# บ้านสวน Monitor — 3D Digital Twin + เรดาร์ + Hub อุปกรณ์

เว็บสำหรับเฝ้าดูบ้านสวน มี 3 แท็บ

| แท็บ | สิ่งที่ทำได้ตอนนี้ (prototype) | ต่อยอดเป็นของจริง |
|---|---|---|
| 🏡 **บ้านสวน 3D** | บ้านแบบโมเดิร์นทรอปิคอลตามรูปตัวอย่าง, ระเบียงไม้, โรงรถ, รั้วกับประตู, บ่อปลา (ปลาว่ายและกระโดด), คอกหมู 6 ตัว, เล้าไก่ 8 ตัว, โรงเรือนผักไฮโดรโปนิกส์แบบ NFT, **สวนยางพารา 400 ต้น** (20×20 ต้น ระยะ 3×7 ม.), นาข้าว หมอกยามเช้า และเวลากลางวัน/กลางคืน · **มีการเคลื่อนไหว**: พ่อเดินไปเอาอาหาร → เทใส่ราง → หมูวิ่งมากิน, แม่เดินในบ้าน, พัดลมเพดานหมุน, หมาวิ่งไปหาคนแปลกหน้า | ตำแหน่งคนกับสัตว์มาจากเซนเซอร์จริง และสถานะอุปกรณ์มาจาก MQTT |
| 📡 **เรดาร์** | HUD สีเขียวตามรูปอ้างอิง มีเส้นกวาด ผังบ้าน และเขตรั้ว · เมื่อ**คนที่ไม่ใช่คนในบ้าน**เดินเข้ารั้ว → กล้องถ่ายหน้า → **แจ้งเตือนเข้ามือถือพร้อมรูป** → กด **รู้จัก (Allow)** แล้วตั้งชื่อ ครั้งหน้าระบบจะจำได้เอง / กด **ไม่รู้จัก** → เปิดไฟสปอตไลท์ + ไซเรน · ใช้เว็บแคมจริงแทนกล้องจำลองได้ และมีแจ้งเตือนของระบบพร้อมปุ่ม (Service Worker) | mmWave + กล้อง AI ตรวจจับคน, Face recognition, Push ผ่าน LINE/Telegram/Web Push |
| 🛰️ **Hub** | การ์ดเซนเซอร์ 8 โซน (อากาศ, ไฮโดร pH/EC, บ่อปลา DO, คอกหมู NH₃/ไซโล, เล้าไก่, สวนยาง, โซลาร์, ความปลอดภัย) พร้อมกราฟ · สวิตช์สั่งงานที่**ไปขยับฉาก 3D จริง** (ปั๊ม, เครื่องเติมอากาศ → ฟองในบ่อ, ประตูเล้า, ไฟ, ประตูรั้ว, สั่งให้อาหารหมู → พ่อเดินไปให้) · **เชื่อม MQTT over WebSocket ได้จริง** | ESP32 / Raspberry Pi ส่งค่าเข้า topic เดียวกัน |

## ครอบครัวและสัตว์เลี้ยงในฉาก

- **พ่อ** — ให้อาหารหมูตามกิจวัตร (สั่งจาก Hub ได้)
- **แม่** — อยู่ในบ้าน (มองเห็นผ่านกระจก)
- **พี่สาว** — ตรวจผักในโรงเรือนไฮโดรโปนิกส์ แล้วไปเก็บไข่ไก่ (ยอดไข่ใน Hub จะเพิ่มขึ้นตามจริง)
- **น้องสาว** — เล่นในสวน และไปให้อาหารปลา ปลาจะว่ายมารวมกันที่ขอบบ่อ หมามักวิ่งตามเธอ
- **แมว 6 ตัว** — ส้ม, ดำ, ขาว, สามสี, สลิ่ม, วิเชียรมาศ เดินเล่น นอนขดบนระเบียง นั่งเฝ้าบ่อปลา และเดินตามน้องสาว

ทั้ง 4 คนเป็น "ครอบครัว" ที่ระบบรู้จักอยู่แล้ว เรดาร์จะไม่แจ้งเตือน และรูปหน้าจะขึ้นในส่วน "ครอบครัว" ของมือถือจำลอง

## 🎬 กล้องเล่าเรื่อง (ปล่อยไว้เฉย ๆ)

ถ้าไม่ได้แตะหน้าจอ 20 วินาที กล้องจะเริ่มเล่าเรื่องเอง หรือกดปุ่ม **🎬 เล่าเรื่องอัตโนมัติ** ในแผงควบคุมก็ได้ จะมีแถบดำแบบภาพยนตร์และคำบรรยายที่อัปเดตตามสิ่งที่เกิดขึ้นจริงในฉาก
ลำดับช็อต: ภาพมุมสูงทั้งสวน (พร้อมเวลาและอากาศจริง) → บ้าน → ตามพ่อ → คอกหมู → ตามพี่สาว → ตามน้องสาว → ตามแมว → บ่อปลา → เล้าไก่ → เดินผ่านโรงเรือนผัก → บินลอดสวนยาง 400 ต้น → วนใหม่
- กล้องตามตัวละครจริง จึงเห็นว่าแต่ละคนกำลังทำอะไรอยู่ตอนนั้น เช่น "พ่อ — ถืออาหารไปที่รางหมู"
- ถ้ามีคนแปลกหน้าเดินเข้ามา กล้องจะตัดไปหาคนนั้นทันที
- แตะ ลาก หรือซูมฉากเมื่อไร จะหยุดและคืนการควบคุมทันที เปิด/ปิดการเริ่มเองได้ที่ "เริ่มเองเมื่อปล่อยไว้ 20 วินาที"
- เหมาะเปิดค้างไว้บนแท็บเล็ตหรือทีวีที่บ้าน

## แจ้งเตือนจริงเข้ามือถือ (Telegram)

ส่ง**รูปหน้าคนแปลกหน้าพร้อมปุ่ม ✅ รู้จัก / 🚨 ไม่รู้จัก** เข้ากลุ่ม Telegram ของครอบครัวได้จริง ทุกคนในกลุ่มจะได้รับพร้อมกัน ใครกดก่อนก็ได้ ระบบจะบันทึกว่าใครเป็นคนตอบ แล้วแก้ข้อความเดิมให้ทุกคนเห็นผล
- กด **รู้จัก** → บอทจะถามชื่อ ให้กด Reply แล้วพิมพ์ชื่อ → ระบบจำคนนี้ไว้ ครั้งหน้าจะส่งแค่ "✅ ลุงสมชาย มาถึงบ้านแล้ว"
- กด **ไม่รู้จัก** → เปิดไฟสปอตไลท์ + ไซเรน และแจ้งในกลุ่ม
- เมื่อข้อมูลอากาศจริงเปลี่ยนเป็น **พายุฝนฟ้าคะนอง** ระบบจะแจ้งเตือนในกลุ่มด้วย

**ต้องเตรียม (ประมาณ 5 นาที ไม่มีค่าใช้จ่าย):**
1. ทุกคนในบ้านติดตั้งแอป Telegram
2. ทักแชท **@BotFather** → พิมพ์ `/newbot` → ตั้งชื่อ เช่น `บ้านสวน Monitor` แล้วตั้ง username ให้ลงท้ายด้วย `bot` → จะได้ **Bot token**
3. สร้างกลุ่ม "ครอบครัว" ที่มีพ่อ แม่ พี่สาว น้องสาว แล้ว**เพิ่มบอทเข้ากลุ่ม** และพิมพ์อะไรสักอย่างในกลุ่ม 1 ครั้ง
4. ในเว็บ ไปที่แท็บ **เรดาร์ → PUSH NOTIFICATION → 📲 Telegram** ใส่ Bot token → กด **ค้นหา** → เลือกกลุ่ม → **บันทึก & เชื่อมต่อ** → **ส่งทดสอบ** แล้วลองกดปุ่มในมือถือ
5. กด **🚶 จำลองคนแปลกหน้าที่ประตู** เพื่อลองการแจ้งเตือนเต็มรูปแบบ

**ข้อควรรู้:**
- token เก็บไว้ในเบราว์เซอร์ของเครื่องที่ตั้งค่าเท่านั้น ไม่อยู่ใน repo หรือบนเว็บ **ห้ามส่ง token ให้คนอื่นหรือ commit ลงโค้ด** ถ้าหลุดให้สั่ง `/revoke` กับ @BotFather
- การกดปุ่มใน Telegram ต้องมี**เครื่องเปิดหน้าเว็บนี้ค้างไว้** 1 เครื่อง (เช่น แท็บเล็ตหรือคอมที่บ้าน) เพราะระบบรับคำตอบด้วยการ polling เมื่อมีฮาร์ดแวร์จริงแล้ว ให้ Raspberry Pi ทำหน้าที่นี้แทน
- ตอนนี้ "คนแปลกหน้า" มาจากฉากจำลอง เมื่อต่อกล้องจริงและ Frigate แล้ว จุดที่ส่งแจ้งเตือนจะเหมือนเดิม
- ถ้าต้องการใช้ **LINE** แทน ต้องมีเซิร์ฟเวอร์เล็ก ๆ เพิ่ม (เช่น Cloudflare Worker ฟรี) เพราะ LINE Messaging API เรียกจากเบราว์เซอร์ไม่ได้ และต้องมี webhook รับการกดปุ่ม

## สภาพอากาศจริง (ฝน / เมฆ / พายุฝนฟ้าคะนอง)

- **ดึงข้อมูลจริงจาก [Open-Meteo](https://open-meteo.com/)** ฟรี ไม่ต้องใช้ API key อัปเดตทุก 10 นาที ได้อุณหภูมิ ความชื้น ปริมาณฝน เมฆ ลม และรหัสสภาพอากาศ (WMO code)
- รหัสสภาพอากาศแปลงเป็นเอฟเฟกต์ในฉาก 3D: เมฆครึ้ม, ฝนปรอยถึงฝนหนัก (ความแรงตามปริมาณฝนจริง), หมอก และ **พายุฝนฟ้าคะนอง (รหัส 95–99) → ฟ้าแลบ/ฟ้าผ่า**
- ฟ้าผ่ามีสายฟ้าพร้อมแสงวาบทั้งฉาก ส่วน **เสียงฟ้าร้องจะดังช้ากว่าแสงตามระยะจริง** (เสียงเดินทาง 343 ม./วินาที) ทุกจุดที่ฟ้าผ่าจะขึ้นในเรดาร์และบันทึกในเหตุการณ์
- พื้นถนน คอนกรีต และระเบียงจะดูเปียกตอนฝนตก ต้นมะพร้าวจะโยกตามแรงลมจริง
- ตำแหน่งเริ่มต้นคือกรุงเทพฯ กดปุ่ม **📍 ใช้ตำแหน่งบ้านสวน (GPS)** ตอนยืนอยู่ที่บ้านสวน ระบบจะจำตำแหน่งนั้นไว้
- ค่าอุณหภูมิ ความชื้น และฝนจาก Open-Meteo จะขึ้นในการ์ด "สภาพอากาศ" ของ Hub เป็น `LIVE · Open-Meteo`
- มีโหมดจำลอง (แจ่มใส / ครึ้ม / ฝนตก / ฟ้าคะนอง) ไว้สาธิตให้ดู และมีตัวเลือก "ใช้เวลาจริง" ให้แสงในฉากตรงกับเวลาจริง

**ข้อจำกัด:** Open-Meteo บอกได้แค่ว่า "มีพายุฝนฟ้าคะนองในพื้นที่" แต่ไม่มีพิกัดฟ้าผ่าจริง ตำแหน่งฟ้าผ่าในฉากจึงเป็นการสุ่ม ถ้าต้องการพิกัดจริงมีทางเลือกดังนี้
- **Blitzortung.org** — เครือข่ายตรวจจับฟ้าผ่าแบบเรียลไทม์ ข้อมูลฟรี แต่ใช้ได้เฉพาะงานที่ไม่ใช่เชิงพาณิชย์ และต้องขออนุญาต
- **กรมอุตุนิยมวิทยา (TMD API)** และเรดาร์ฝน ต้องสมัครขอ key
- **เซนเซอร์ฟ้าผ่า AS3935** (~500 ฿) ต่อกับ ESP32 ตรวจฟ้าผ่าได้ในรัศมีราว 40 กม. แล้วส่งระยะผ่าน MQTT เข้า Hub ได้เลย

## วิธีรัน

ต้องเปิดผ่าน http server (เพราะใช้ ES modules กับ Service Worker)

```bash
python -m http.server 5173
```

แล้วเปิด <http://localhost:5173> (เพิ่ม `?tab=radar` หรือ `?tab=hub` เพื่อเปิดแท็บนั้นตรง ๆ)
ไม่ต้อง build อะไร เพราะ Three.js r160 โหลดผ่าน CDN

```
index.html        โครงหน้า + 3 แท็บ
css/style.css     ธีม (เขียวเข้ม / HUD)
js/main.js        สลับแท็บ, นาฬิกา, เชื่อมแท็บต่าง ๆ เข้าด้วยกัน
js/bus.js         event bus กลาง (cmd / alert / farm-event)
js/farm3d.js      ฉาก 3D ทั้งหมด (procedural ไม่ต้องใช้ไฟล์โมเดล) + API ให้เรดาร์: getEntities(), captureFace()
js/radar.js       HUD เรดาร์, ตรวจจับ, ถ่ายหน้า, แจ้งเตือน, รายชื่อคนที่รู้จัก
js/hub.js         แดชบอร์ดเซนเซอร์ + MQTT
sw.js             Service Worker: แจ้งเตือนที่มีปุ่ม รู้จัก/ไม่รู้จัก + รองรับ Web Push
```

## ผลประเมิน: ทำได้ไหม?

**ทำได้ทั้งหมด** แต่ความยากแต่ละส่วนต่างกันมาก

| ส่วน | ความเป็นไปได้ | หมายเหตุ |
|---|---|---|
| ฉาก 3D สมจริงด้วย Three.js | ✅ สูง | ตอนนี้เป็น low-poly ที่สร้างด้วยโค้ด ถ้าจะให้สมจริงระดับรูปถ่าย ต้องปั้นโมเดลใน **Blender → export glTF/GLB** แล้วใช้ texture PBR, HDRI และ baked lighting แต่โครงโค้ดเดิมยังใช้ต่อได้ เปลี่ยนแค่ตัวโมเดล |
| สวนยาง 400 ต้น | ✅ สูง | ใช้ `InstancedMesh` วาด 400 ต้นในไม่กี่ draw call · มือถือรุ่นกลางยังลื่น |
| ตัวละครเคลื่อนไหว (พ่อให้อาหารหมู ฯลฯ) | ✅ สูง | ตอนนี้ใช้ state machine กับ waypoint · ถ้าอยากได้ท่าทางสมจริง ใช้โมเดลที่มีกระดูกจาก **Mixamo** แล้วเล่นด้วย `AnimationMixer` |
| เรดาร์ตรวจจับ "สิ่งมีชีวิต" | ⚠️ ปานกลาง | **ไม่มีเซนเซอร์ตัวเดียวที่คลุมทั้งสวนได้** ต้องผสมหลายแบบ (ดูตารางฮาร์ดแวร์ด้านล่าง) · mmWave ราคาถูกตรวจได้ราว 6–8 ม. จึงเหมาะกับประตูหรือหน้าบ้าน ส่วนพื้นที่กว้างควรใช้**กล้อง + AI ตรวจจับคน** |
| ถ่ายหน้าแล้วส่งเข้ามือถือพร้อมรูป | ✅ สูง | LINE Messaging API, Telegram Bot หรือ Web Push (PWA) ส่งรูปได้ทั้งหมด · **หมายเหตุ: LINE Notify ปิดบริการไปแล้ว (31 มี.ค. 2025)** ห้ามออกแบบโดยพึ่งมัน |
| ปุ่ม "รู้จักไหม" บนมือถือ | ✅ สูง | Telegram มีปุ่ม inline, LINE ใช้ Flex Message + postback, Web Push ใช้ `actions` (ทำไว้ใน `sw.js` แล้ว) |
| จดจำใบหน้า (คนที่กดรู้จักแล้วไม่ต้องถามซ้ำ) | ⚠️ ปานกลาง | ตอนนี้จำลองด้วยรหัสบุคคล · ของจริงใช้ **CompreFace / InsightFace / Frigate + Double Take** บนเครื่องในบ้าน · ความแม่นยำขึ้นกับมุมกล้อง แสง และความละเอียด กลางคืนต้องใช้กล้อง IR |
| Hub ฮาร์ดแวร์ในอนาคต | ✅ สูง | ใช้ MQTT เป็นมาตรฐานกลาง หน้าเว็บนี้ subscribe ได้แล้ว |

### สถาปัตยกรรมที่แนะนำ (ระบบจริง)

```
 [ESP32 เซนเซอร์ทุกโซน] ──WiFi/LoRa──┐
 [mmWave LD2450 ที่ประตู] ───────────┤
 [กล้อง IP / RTSP 2–4 ตัว] ──► [Mini PC / Raspberry Pi 5 + Coral]
                                    │   ├─ Mosquitto (MQTT broker, WebSocket)
                                    │   ├─ Frigate (ตรวจจับคน/สัตว์ด้วย AI)
                                    │   ├─ Double Take / CompreFace (จดจำใบหน้า)
                                    │   └─ Node-RED หรือ API เล็ก ๆ (logic + แจ้งเตือน)
                                    ▼
                 ┌──────── เว็บนี้ (3D / เรดาร์ / Hub) ← MQTT over WSS
                 └──────── LINE OA / Telegram Bot / Web Push → มือถือ (กด รู้จัก / ไม่รู้จัก)
```

Flow ตอนมีคนแปลกหน้า: Frigate ตรวจพบ `person` ในโซนรั้ว → ครอปหน้า → Double Take เทียบกับคนที่รู้จัก →
ถ้า **ไม่รู้จัก** ส่งรูปเข้ามือถือพร้อมปุ่ม → ผู้ใช้กด **รู้จัก** แล้วตั้งชื่อ → เอารูปไป train เพิ่ม / กด **ไม่รู้จัก** → MQTT `cmd/lights` + ไซเรน

### ฮาร์ดแวร์เริ่มต้น (ประมาณการ ราคาในไทย)

| อุปกรณ์ | ใช้ทำอะไร | ราคาโดยประมาณ |
|---|---|---|
| Raspberry Pi 5 8GB หรือ Mini PC N100 | ศูนย์กลาง (MQTT, Frigate, ระบบจดจำหน้า) | 3,000–6,000 ฿ |
| Google Coral USB (ถ้ามี) | เร่งการตรวจจับด้วย AI | ~2,500 ฿ |
| กล้อง IP มี IR + RTSP 2–4 ตัว | หน้าบ้าน ประตู คอกหมู | 800–1,500 ฿/ตัว |
| HLK-LD2450 mmWave | ตรวจจับคนพร้อมพิกัด X-Y ที่ประตูหรือหน้าบ้าน (~6 ม.) | ~400 ฿ |
| ESP32 + DHT22/BME280 | อากาศ คอกหมู เล้าไก่ | 300–500 ฿/จุด |
| หัววัด pH + EC + DS18B20 | ไฮโดรโปนิกส์ | 1,500–3,000 ฿ |
| หัววัด DO | บ่อปลา (หัววัดดี ๆ ราคาสูง) | 3,000–8,000 ฿ |
| โมดูล LoRa (SX1276) 2 ตัว | สวนยางที่ไกลเกินระยะ WiFi | ~1,000 ฿ |
| รีเลย์ 4 ช่อง + ปั๊ม/เครื่องเติมอากาศเดิม | สั่งงานจาก Hub | ~300 ฿ |

### MQTT topic ที่หน้าเว็บรองรับแล้ว

ค่าเริ่มต้นของ prefix คือ `banshuan/demo` (เปลี่ยนในช่องบนแท็บ Hub ได้) · payload ส่งเป็นตัวเลข `6.2` หรือ `{"value":6.2}` ก็ได้

```
<prefix>/weather/temp | humidity | light | rain
<prefix>/hydro/ph | ec | water_temp | level
<prefix>/pond/do | water_temp | level
<prefix>/pig/temp | nh3 | feed
<prefix>/chicken/eggs | temp
<prefix>/rubber/latex | soil
<prefix>/energy/solar | battery
คำสั่งจากเว็บ →  <prefix>/cmd/<device>   (hydro-pump, aerator, chicken-door, lights, gate, pig-feeder)
```

ลองส่งค่าจากคอมพิวเตอร์ได้เลย (broker สาธารณะ ใช้ทดสอบเท่านั้น):
`mosquitto_pub -h broker.emqx.io -t banshuan/demo/hydro/ph -m 7.4` → การ์ด pH จะขึ้น LIVE และเป็นสีแดงเพราะเกินช่วงปกติ

### แผนพัฒนาต่อ

1. **ระยะ 1 (เสร็จแล้ว)** — prototype เว็บ 3 แท็บ ใช้ข้อมูลจำลอง
2. **ระยะ 2** — ปั้นบ้านใน Blender ตามขนาดจริง (วัดผังบ้าน) แล้วเปลี่ยนเป็น GLB + ตัวละครจาก Mixamo
3. **ระยะ 3** — ติดตั้ง Pi + Mosquitto + กล้อง 1 ตัวหน้าประตู + Frigate → เชื่อมแท็บเรดาร์กับข้อมูลจริง
4. **ระยะ 4** — LINE OA หรือ Telegram Bot สำหรับแจ้งเตือนพร้อมปุ่ม + Double Take จดจำหน้า
5. **ระยะ 5** — ESP32 เซนเซอร์ทีละโซน (เริ่มที่ไฮโดรโปนิกส์กับบ่อปลา เพราะคืนทุนเร็วที่สุด)

### ข้อควรระวัง

- **PDPA**: การเก็บรูปหน้าคนนอกบ้านถือเป็นข้อมูลส่วนบุคคล ควรติดป้าย "พื้นที่มีกล้องวงจรปิด" เก็บรูปไว้ในเครื่องที่บ้าน และตั้งให้ลบอัตโนมัติ (เช่น 30 วัน)
- อย่าเปิดหน้าเว็บกับ MQTT ออกอินเทอร์เน็ตตรง ๆ ควรใช้ **Tailscale / Cloudflare Tunnel** พร้อมระบบล็อกอิน
- broker สาธารณะ (`broker.emqx.io`) ใช้ทดสอบเท่านั้น ของจริงต้องใช้ broker ของตัวเองที่มีรหัสผ่านกับ TLS
